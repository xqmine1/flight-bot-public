# flight-bot-public

## Монитор очень дешёвых билетов

Отдельный сценарий `deal_monitor.py` проверяет цены из Алматы и Ташкента во все направления, для которых Travelpayouts возвращает данные в своём кэше. Он ищет билеты в одну сторону на ближайшие 180 дней, сравнивает цену с медианой по тому же маршруту, месяцу вылета и числу пересадок и отправляет уведомление при снижении не менее чем на 30%. Снижение от 40% помечается как особенно сильное.

Для ориентира бот копит ежедневные цены по каждому направлению, месяцу вылета и числу пересадок. Он начинает сравнивать цену с исторической медианой после пяти дневных наблюдений; новые или редкие направления могут начать давать уведомления не сразу.

Workflow `.github/workflows/deal-monitor.yml` настроен на запуск раз в два часа и ручной запуск. В GitHub Actions должны быть заданы секреты `TELEGRAM_TOKEN`, `TELEGRAM_CHAT_ID` и `TRAVELPAYOUTS_TOKEN`. Расписание начнёт работать после попадания workflow в ветку по умолчанию; после этого его можно запускать вручную для выбранной ветки.

Источник цен — официальный кэш Aviasales/Travelpayouts, а не прямое наличие билетов у перевозчика. Кэш покрывает направления, по которым есть недавние поисковые данные, поэтому это широкий поиск по доступным предложениям, а не гарантированный полный перечень всех рейсов мира. Перед покупкой нужно открыть ссылку и проверить актуальную цену.
